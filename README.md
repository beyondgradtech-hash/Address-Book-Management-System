
# Address Book Management System in C

## Project Overview
A menu-driven Contact Management System developed using C programming as part of my Embedded Systems training at Emertxe.

## Features
- Add new contacts
- Display all contacts
- Search contacts by name, phone number, or email
- Edit existing contacts
- Delete contacts
- Validate phone numbers and email addresses
- Store contact details using file handling

## Technologies Used
- C Programming
- GCC Compiler
- Linux
- CSV File Handling

## Concepts Applied
- Structures
- Arrays
- Pointers
- Functions
- String Handling
- File Handling
- Conditional Statements and Loops

## Project Files
- `main.c` – Main program execution
- `addressbook.c` – Contact management functions
- `addressbook.h` – Header file and structure definitions
- `database.csv` – Contact data storage

## How to Compile and Run

Compile:
```bash
gcc main.c addressbook.c -o addressbook
```

Run:
```bash
./addressbook
```

## Learning Outcomes
This project helped me gain practical experience in C programming, modular programming, file handling, and implementing CRUD operations.
